### What's New in Cinemora v2.3.12 🎬

- 🧭 **Flawless Floating Navigation Bar Animation**: Completely eliminated the overlapping artifact and extra bottom line when transitioning between static and floating navigation bars. Static docked mode now cleanly uses a top divider without artificial bottom borders, and the floating capsule floats gracefully above system navigation insets with soft, unclipped elevation.
- 🌙 **Concise Pure Dark Mode Description**: Shortened the description for Pure Pitch Black (AMOLED) in Settings to *"Pure #000000 black for OLED"* for a cleaner, more streamlined appearance.
