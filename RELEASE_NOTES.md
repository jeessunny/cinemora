### What's New in Cinemora v2.3.3 🎬

- 🖤 **Pure Pitch Black Isolation**: Fixed theme combining bug where light mode surfaces or dark text could leak into Search and Library screens. AMOLED mode is now strictly isolated to Dark and System modes.
- 🎨 **Flawless Theme Separation**: Refined color tokens and surface containers across Search, Library, Settings, and Details screens for consistent high-contrast aesthetics in both Light and Dark themes.
- 🔍 **Permanent Search Navigation**: Search is now a core permanent tab in the bottom navigation bar (Home, Search, Library, Settings), and the redundant hide-toggle has been removed from Settings.
- ⚡ **Smoother Performance & Clean Borders**: Subtle theme-aware borders and surface highlights on SearchBar, category filters, and dialog components.
