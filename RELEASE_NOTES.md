### What's New in Cinemora v2.3.8 🎬

- 🔤 **Inter Typography System**: Upgraded the entire application to use official **Inter** as the primary font family globally across all UI elements.
- ⚖️ **Refined Font Weights**:
  - **Regular (400)**: Applied to body text, descriptions, and supporting content.
  - **Medium (500)**: Applied to secondary headings, labels, and metadata.
  - **SemiBold (600)**: Applied to screen titles, navigation items, and prominent labels.
  - **Bold (700)**: Applied to display headings and emphasis.
- 🎨 **Centralized & Seamless Design**: Fully centralized theme configuration applying Inter to all screens (Home, Search, Details, Library, Settings, Profile), dialogs, bottom sheets, and search/input fields without changing layouts, colors, or component dimensions.
